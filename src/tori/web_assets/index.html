Local reference

            
Commands

          

        

        
You can ask Tori naturally for most things. Slash commands are optional shortcuts or explicit controls for specific tasks. To run a command, ask Tori or use the supervised Terminal in Chat. This page is an informational reference, not a set of execution controls.


        

          
Browser conversation commands

          

            

              
/search QUERY

              
Run one explicitly authorized web search through the configured local SearXNG service.

            

            

              
/remember TEXT

              
Creates one explicitly approved ordinary memory using the exact supplied text.

              
Graphical equivalent: Memories → Create Memory.

            

            

              
/memories

              
Lists Tori's canonical curated memories.

              
Graphical equivalent: Open Memories.

            

            

              
/update-memory MEMORY_ID NEW_TEXT

              
Replaces the selected memory's current text.

              
Graphical equivalent: Edit the selected record in Memories. Graphical edits also protect against stale record versions.

            

            

              
/forget MEMORY_ID

              
Requests removal of one selected memory. Browser use requires a separate confirmation before removal.

              
Graphical equivalent: Remove the selected record in Memories; confirmation is also required.

            

            

              
/add-knowledge PATH

              
Registers one exact supported local .txt or .md source path.

              
Graphical equivalent: Knowledge → Register Path.

            

            

              
/knowledge

              
Lists knowledge registrations and current availability without source excerpts.

              
Graphical equivalent: Open Knowledge.

            

            

              
/remove-knowledge SOURCE_ID

              
Removes only the selected registration. It never modifies or deletes the source file.

              
Graphical equivalent: Remove the selected record in Knowledge; the graphical action requires confirmation.

            

          

        


        

          
Finance commands

          
Finance slash commands manage initialization and statement-import review. They use configured local Finance storage; proposals and imports require a separate confirmation before durable changes. Ordinary Finance questions do not need a slash command—for example, How much did I spend on fast food this month?, What bills are due next week?, or Can I afford an $800 guitar?

          

            

              
/finance initialize

              
Proposes creating the configured Finance workbook and import folders. Confirmation is required before anything is created.

            

            

              
/finance import FILENAME | FRIENDLY ACCOUNT

              
Previews a statement from Finance imports/incoming/ for the supplied friendly account label.

              
Example: /finance import statement.csv | Citi Card

            

            

              
/finance review

              
Shows unresolved candidates and possible duplicates in the active import preview.

            

            

              
/finance review NUMBER | MERCHANT | CATEGORY

              
Reviews one candidate with an exact normalized merchant and category.

              
Example: /finance review 3 | Amazon | Amazon

            

            

              
/finance review NUMBER | include

              
Includes a possible duplicate after reviewing it.

            

            

              
/finance review NUMBER | exclude

              
Excludes a possible duplicate from the pending import.

            

            

              
/finance review rule NUMBER | exact|starts_with|contains | MATCH | MERCHANT | CATEGORY

              
Adds a reviewed reusable merchant rule to this pending import. The rule becomes durable only if the final import is confirmed.

              
Example: /finance review rule 2 | contains | MCDONALDS | McDonald's | Dining / Fast Food

            

            

              
/finance review propose

              
Creates the exact import proposal once every included candidate is resolved.

            

            

              
/finance review cancel

              
Abandons the transient import review without changing Finance data.

            

          

          
Finance review is available only after a Finance import preview. Unresolved or ambiguous candidates remain local and must be reviewed before a proposal can be produced.

        

        

          
Command notes

          
Not supported: /memory is not a valid command. Unsupported command-shaped input is rejected locally instead of being sent to the model.

        


        

          
What each kind of persistence means

          

            
Curated memories are selected long-term contextual facts.

            
Knowledge registrations reference external source files; they do not copy those files.

            
Conversation archives automatically preserve usable transcripts for listing, opening, resuming, and explicit deletion. They are not curated memories.
